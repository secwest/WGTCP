# Baseline 1.0.0 — TCP-base tunnel vs UDP tunnel scenario summary

- **Image**: `wireguardtcp-ubuntu24-tls/1.0.0` (x64) and `wireguardtcp-ubuntu24-arm64-tls/1.0.0` (arm64)
- **Topology**: point-to-point, 8 isolated 2-VM pairs, one /24 each, ports 51820/UDP + 51821/TCP
- **Tunnel labels** (in matrix.csv): `wireguard-tcp-base` = baseline-image TCP transport (`Transport=tcp`); `wireguard-udp` = stock UDP control
- **Each long-transfer cell** runs `iperf3 -t 60 -P 4` then `iperf3 -u -b 1G -l 1200 -t 60` over the **same** selected tunnel, so both inner-TCP and inner-UDP throughput are recorded for each tunnel choice
- **CPU**: `100 - mpstat %idle`, mean over the cell. Tunnel-level (not protocol-specific).
- **Δ%** is `(tcp_tunnel - udp_tunnel) / udp_tunnel × 100` for the SAME inner-traffic class.
- VM size: x64 = D2s_v5 (2 vCPU), arm = D2ps_v6 (2 vCPU)
