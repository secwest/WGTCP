# Qualified Screening Composite

This is the qualified 68-cell finite-queue and RTT-boundary screening
inventory: 61 valid cells from the initial campaign plus seven valid exact-cell
reruns. All 68 cells are stable; none are degraded, near-meltdown, meltdown, or
invalid.

The composite deliberately retains two campaign fingerprints. Both sources
have identical module srcversion, module SHA-256, userspace tool SHA-256, and
matrix axes. `provenance.csv` records the selected campaign and cell
fingerprint plus analyzed `cell.json` SHA-256 for every row.
`composite-status.json` records the runtime identity, source fingerprints,
counts, and seven replacements.

The original initial report remains published with its seven invalid cells; it
was not edited or overwritten.
